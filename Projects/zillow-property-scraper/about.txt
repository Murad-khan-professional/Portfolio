This n8n workflow automates property and real estate agent data extraction from Zillow listings. The workflow accepts search parameters—location, property type, price range—and uses web scraping techniques to collect listing data from Zillow. For each property, it extracts details including address, price, bedrooms, bathrooms, square footage, listing date, and property images. The workflow also captures agent information—name, brokerage, contact details, and listing count. Data is cleaned, deduplicated, and structured into organized Google Sheets or a database for analysis. The workflow handles pagination to scrape multiple pages of results and includes rate limiting to avoid detection. Error handling logs failed extractions for manual review. This provides real estate professionals with market data and agent insights without hours of manual research.

Tech Stack: n8n, Apify/Web Scraping, Google Sheets API, JavaScript (data parsing), Proxy Management
