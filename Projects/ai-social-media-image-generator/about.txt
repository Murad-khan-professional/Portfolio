This n8n workflow automates social media image generation for blog posts using AI. When a new blog post is published or scheduled, the workflow extracts the post title, key points, and featured content. It crafts optimized prompts and sends them to an AI image generation service (DALL-E, Midjourney API, or Stable Diffusion) to create custom visuals tailored to the blog content. The workflow generates multiple image sizes optimized for different platforms—square for Instagram, landscape for Twitter/LinkedIn, and vertical for Stories. Generated images are automatically uploaded to cloud storage with organized naming conventions and linked back to the blog post record. Optional text overlays add titles or branding. This eliminates the need for manual graphic design while ensuring every blog post has unique, engaging social media visuals ready for promotion.

Tech Stack: n8n, AI Image Generation API (DALL-E/Stable Diffusion), Google Drive API, Image Processing, CMS Webhook/API
