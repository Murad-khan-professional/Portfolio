# HubSpot Deal to Linear Project Sync

## Overview
This automation monitors HubSpot for deals that move to Closed Won and triggers an n8n workflow. The workflow collects deal details and automatically creates a new project in Linear using Linear's API. It ensures consistent project setup and synchronizes sales-to-delivery handoff without manual data entry. All actions run through n8n, integrating HubSpot and Linear seamlessly.

## How It Works
When a HubSpot deal moves to the Closed Won stage, an n8n workflow is triggered automatically. The workflow extracts deal details from HubSpot and creates a corresponding project in Linear via its API, ensuring a seamless and consistent handoff from sales to delivery without any manual intervention.
